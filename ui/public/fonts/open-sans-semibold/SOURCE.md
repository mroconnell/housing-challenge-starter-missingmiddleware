# Open Sans Semibold map glyphs

Signed-distance-field glyph files (PBF) for the map labels, self-hosted so the tool loads no font service at run time.

- Font: Open Sans Semibold (Steve Matteson / Google), Apache License 2.0 (LICENSE.txt in this folder, copied from the source repository's `open-sans/LICENSE.txt`).
- Glyph files: openmaptiles/fonts, branch `gh-pages`, folder `Open Sans Semibold/` (generated with fontnik), commit 025ff2b2f84cc0fdf11f7b1d74b3a784595fe7a4, downloaded 2026-10-26 from https://raw.githubusercontent.com/openmaptiles/fonts/gh-pages/Open%20Sans%20Semibold/{range}.pbf
- Ranges kept: 0-255 (Basic Latin, Latin-1), 256-511 (Latin Extended-A), 8192-8447 (General Punctuation). Other ranges are not shipped; labels use place names in these ranges only.
