# Proposed TOD framework: measure the cause, then carry it to Wisconsin

Ryan's proposal, 2026-11-02, drafted in the learning thread and approved by Ryan to send to the TOD session.

**Goal (the estimand):** net new homes statewide, 2027–2031, caused by the option D district law. That's the district's gain, plus or minus changes next door, minus homes that just moved in from farther away.

## Stage 1: measure the causal effect

1. **Main: station-level difference-in-differences (current method).** Reform stops vs similar stops, before and after. It measures the total effect near the station. Fix for transit: compare stops whose lines are about the same age, and run "rezoned when the line opened" cases as a sensitivity (Saint Paul, Othello, Honolulu, the Hop).
2. **Floor: edge test (difference-in-discontinuities).** Lots just inside vs just outside each district, before and after. It measures the direct effect on rezoned lots.
3. **Ceiling: citywide net check.** Extra permits per 1,000 homes in the whole city, using the Census permit survey, for all 11 district places (the Oct 27 study covered 8 cities). It catches homes that moved within the city.
4. **Mandate discount: Massachusetts MBTA Communities.** Towns forced to zone vs towns not yet due. It tests whether a mandated district performs like a chosen one. Run it if town-level permit data can be had.

**Units:** lead with extra homes per 100 lot acres a year. Show two checks beside it: the district's share of the city's new homes, and homes per unit of added capacity. Say so plainly if the story changes by unit.

## Stage 2: carry it to Wisconsin

1. **Headline: plain average × Wisconsin district acres × 5 years.** It already beats every model on hidden places.
2. **Sensitivity: one-trait adjustment** (home values or rents), kept only if it beats the plain average on the hide-one-place test.
3. **Guardrail: reality cap.** The total must stay within what similar metros have ever permitted in a year.
4. **Spillover range:** district only (current), plus the next-door ring (small, per the Oct 27 study), and a downside case where part of the district's homes moved from elsewhere.
5. **After launch:** write the update rule now. Shift the estimate toward Milwaukee's and Madison's own results as their permits come in from 2027.

**Rules:** lock each test's pass rule before running it, and label anything found after looking at results.
