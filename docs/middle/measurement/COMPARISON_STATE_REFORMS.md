# Comparison-state reform screen (2–4 unit test)

Prepared 2026-11-09 (UTC). Only laws, dates and what they do. No permit counts or outcomes recorded (no-peeking rule kept; where a source showed post-2018 counts they were skipped).

Key:
- **V** = official page (legislature, state agency, city government, or repo row marked verified).
- **S** = secondary (law firm, news, advocacy, search summary).
- **K** = from prior knowledge only, not re-checked this pass. Treat as a lead.
- "Affects 2–4?" = could plausibly raise permits for new 2–4 unit buildings in Census BPS: **yes / maybe / no**.
- Note on ADUs: in BPS a detached ADU is usually a separate 1-unit building or not counted; an attached ADU or a conversion may appear as a 2-unit building or not at all. So ADU laws are scored **maybe**, not yes.
- Windows to watch: West after-window 2023–2025; Northeast after-window 2023–2025; before-windows start 2015 (OR), 2018 (CA), 2019 (ME, VT).
